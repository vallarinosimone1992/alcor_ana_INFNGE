{\small updated for the current TDC/offset/timewalk chain}

\section*{Reconstructed Time}
For each hit, the coarse and fine timestamp is converted to ns as:
\begin{align*}
  T_\mathrm{tick} &= 32768\,\mathrm{rollover} + \mathrm{coarse}, &
  \Delta t_\mathrm{clk} &= \frac{1000}{\mathrm{clock\_MHz}}, \\
  i_\mathrm{TDC} &= \mathrm{tdc} + 4\,\mathrm{pixel} + 16\,\mathrm{column} + 128\,\mathrm{fifo}, &
  t_0 &= \left(T_\mathrm{tick} - \phi(\mathrm{fine}, i_\mathrm{TDC})\right)\Delta t_\mathrm{clk}.
\end{align*}
\(\phi\) is the calibrated fine-time fraction. It is read from the \texttt{hFineLut} LUT; if the LUT is disabled or missing, the code falls back to the linear min/max map for that TDC. With \texttt{--no-fine}, \(\phi=0\).

The TDC/channel-offset calibration applied while reading hits is:
\[
  t = t_0 - O_{\mathrm{ch},\mathrm{tdc}} .
\]
\(O_{\mathrm{ch},\mathrm{tdc}}\) is the relative channel/TDC offset stored in \texttt{hChannelTdcOffset}. By default it is extracted relative to channel 22; alternatively, an event-median reference can be used.

The ToT is computed within the same spill and channel by pairing each leading TDC with its trailing partner:
\[
  \mathrm{ToT}=t_{\mathrm{trailing},0}-t_{\mathrm{leading},0},\qquad 0 < \mathrm{ToT} \le \texttt{--duration}.
\]
The ToT uses the fine-calibrated raw time \(t_0\), not the time already corrected for offsets.

\section*{TDC and Offset Calibration}
Basic command:
\begin{verbatim}
./script/run_tdc_calibration.sh -i ../data/RUN -d 50
\end{verbatim}
It produces \texttt{calibration/TDC\_calibration.root} and \texttt{output/TDC\_calibration.pdf}. The script checks from the logbook that the run is in opmode 1 unless \texttt{--skip-logbook-check} is passed.

Main options:
\begin{itemize}
  \item \texttt{--q-low}, \texttt{--q-high}, \texttt{--min-entries}: quantiles and minimum statistics for the fine LUT.
  \item \texttt{--match-coincidence} and \texttt{-d NS}: build the LUT using leading hits with valid ToT within the requested duration; default: use all leading hits.
  \item \texttt{--offset-study}/\texttt{--no-offset-study}: enable or disable the offset study, enabled by default.
  \item \texttt{--offset-reference 22}: default, reference offsets to channel 22.
  \item \texttt{--offset-reference event-median --offset-min-channels N}: use the event median as reference.
  \item \texttt{--offset-window NS} and \texttt{--offset-event-window NS}: windows used to associate hits from the same laser event.
  \item \texttt{--offset-channels logbook|all|CSV}: channels included in the offset study; default \texttt{logbook}.
\end{itemize}

\section*{TimeWalk Correction}
The calibration uses the relation between sensor ToT and:
\[
  \Delta t = t_\mathrm{sensor} - t_\mathrm{ref}.
\]
By default \(t_\mathrm{ref}\) is the cleaned channel-22 laser trigger; \texttt{--reference-mode event-median} is available for event-reference studies. The fit gives a function \(f_\mathrm{ch}(\mathrm{ToT})\), and the applied correction is:
\[
  t_\mathrm{TW} = t - f_\mathrm{ch}(\mathrm{ToT}).
\]
This aligns the corrected sensor time to the chosen reference. The default model is \texttt{pol1-plateau}:
\[
  f(\mathrm{ToT}) = p_0 + p_1 \min(\mathrm{ToT}, x_0).
\]
The alternatives are \texttt{pol1} and \texttt{lin-exp-plateau}.

Basic command:
\begin{verbatim}
./script/run_timewalk_calibration.sh -i ../data/RUN -d 50 --signed-dt
\end{verbatim}
It produces \texttt{calibration/timewalk\_correction.root}. The macro applies the correction for closure plots and writes the \texttt{timewalk\_corr\_*} parameters. The standard analysis automatically uses this file when present; disable it with:
\begin{verbatim}
./script/run_analysis.sh -i ../data/RUN --no-timewalk
\end{verbatim}

\section*{Available Cuts and Selections}
\begin{itemize}
  \item Active channels: read from the logbook; override with \texttt{--channels CSV} or \texttt{--sensors CSV}. In trigger mode, \texttt{--trigger 22} is removed from the sensor list.
  \item Fine wrap: \texttt{--fine-cut N} rejects hits with \(\mathrm{fine}\) close to the TDC cut; \texttt{--no-fine} disables fine correction; \texttt{--no-lut} uses the linear min/max map.
  \item Valid ToT: required by default in timewalk mode; \texttt{--no-require-tot} allows leading hits without valid ToT. \texttt{-d NS} sets the maximum accepted ToT; \texttt{run\_analysis.sh} also supports \texttt{--min-duration NS}.
  \item Spill range: \texttt{--spill-range MIN:MAX} reads only the selected inclusive spill range.
  \item Channel-22 trigger: \texttt{--trigger-tot-window MIN:MAX} cuts on trigger ToT; \texttt{--trigger-veto NS} rejects rebounds within NS after an accepted trigger; \texttt{--trigger-period NS} and \texttt{--trigger-period-tol NS} keep only triggers compatible with the expected period.
  \item Event/matching window: \texttt{--window NS} is the coincidence window; \texttt{--event-window NS} defines event building and defaults to \texttt{--window}; \texttt{--signed-dt} uses the nearest trigger and keeps the sign.
  \item TDC selection: \texttt{--tdc-selection 0} or \texttt{--tdc-selection 17:0,19:2,22:0}; the leading TDC is selected while the trailing partner is kept for ToT.
  \item Per-channel ToT window: \texttt{--channel-tot-window CH:MIN:MAX[,CH:MIN:MAX]}.
  \item Diagonal \(\Delta t\)/ToT cut: \texttt{--dt-tot-cut CH:DT0:SLOPE[:TOT\_MIN:TOT\_MAX]}. With the default \texttt{--dt-tot-cut-direction below}, the accepted region is \(\Delta t \le DT0 + SLOPE\cdot\mathrm{ToT}\); \texttt{above} keeps the opposite side.
  \item Timewalk fit: \texttt{--timewalk-fit-ranges CH:MIN:MAX[,CH:MIN:MAX]} limits the TProfile points used by the fit; \texttt{--timewalk-fit-model} selects \texttt{pol1}, \texttt{pol1-plateau}, or \texttt{lin-exp-plateau}.
  \item Final analysis: \texttt{run\_analysis.sh} applies TDC/offset calibration with \texttt{-k calibration/TDC\_calibration.root}; it applies timewalk with \texttt{--timewalk-calib FILE}, or automatically if \texttt{calibration/timewalk\_correction.root} exists. \texttt{--window}, \texttt{-d}, \texttt{--min-duration}, and \texttt{--fine-cut} remain operational overrides.
\end{itemize}

\section*{Minimal Diagnostics}
In the timewalk PDF, TH2 maps and TProfiles are printed on separate pages: use TH2 maps to inspect populations and cuts, and TProfiles to inspect the fit. The coincidence peak for the first sensor pair, normally 17--19, is saved before and after timewalk (\texttt{h\_dt\_uncorr\_*}, \texttt{h\_dt\_corr\_*}) and overlaid in a \texttt{THStack} in the PDF.
